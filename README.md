# LAST LINE

A browser-based tactical FPS prototype.

## Features

- 3D first-person gameplay
- Four missions
- Multiple weapons
- Enemy AI
- Health and damage
- Reloading
- XP and progression
- Mission objectives
- On-screen mission radio dialogue
- Desktop controls
- Basic mobile buttons
- Multiplayer server foundation
- No game audio

## Controls

W A S D = Move

Mouse = Aim

Left Click = Fire

R = Reload

Mobile buttons = Fire / Reload / Switch

## Run

The client can be hosted on GitHub Pages.

The multiplayer server requires Node.js.

Inside server:

npm install

npm start
